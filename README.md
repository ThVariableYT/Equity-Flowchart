# Equity Advisory Flowchart & Landing Page

An interactive, responsive single-page application and decision flow engine designed to guide investors, founders, and stakeholders through equity advisory processes, investment pathways, and financial decision trees.

---

## 📌 Features

- **Interactive Decision Tree**: Visualized flowchart architecture that simplifies complex equity assessments into straightforward, sequential decisions.
- **Client-Side Responsiveness**: Built with clean, modern HTML5 and responsive styling for seamless access across mobile, tablet, and desktop devices.
- **Zero Build Configuration**: Lightweight architecture containing self-contained frontend code without requiring heavyweight frameworks, Node.js runtimes, or external bundlers.
- **Modern UI Elements**: Polished landing page layout designed to communicate advisory services, methodology, and conversion pathways clearly.
